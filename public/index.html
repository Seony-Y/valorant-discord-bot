주요 기능

전적 분석

경쟁전·일반게임 기록과 시즌별 경기 흐름을 확인합니다.

스킬 사용 기록

최근 경기의 Q·C·E·X 사용량과 KDA를 게임별로 확인합니다.

팀 밸런싱

파워 스코어를 기준으로 팀을 자동 구성합니다.

다중 계정 상점

여러 Riot 계정을 저장하고 기본 계정을 선택해 오늘의 상점을 확인합니다.

팀 결과 상세화

플레이어별 티어·점수와 팀별 합계·평균·점수 차이를 표시합니다.

계정 상태와 알림

내 계정과 쿠키 상태를 확인하고 매일 상점 DM 알림을 설정합니다.

처음 사용하기

/전적최근 경기와 시즌 기록
/팀짜기2팀 또는 3팀 구성
/상점연동계정명별 QR 승인
/내정보연동 상태 확인

/전적전적 조회 · 상세 옵션

기본 전적, 경기별 기록, 스킬 사용 기록, 다른 계정 조회를 한 곳에서 확인합니다.

/전적 경기별:TRUE · 최근 경기 상세

/전적 스킬사용기록:TRUE · 게임별 Q·C·E·X 사용량과 KDA

/전적 이름:닉네임 태그:KR 지역:kr · 다른 계정 조회

/전적 시즌:에피소드명 · 선택 시즌 기록

/팀짜기팀 밸런싱

등록된 Riot 계정만 수동 팀 참가가 가능합니다.

/팀짜기 방식:수동 팀수:2 · 참가 버튼으로 팀 구성

/팀짜기 방식:자동 팀수:3 · 파워 스코어 기반 자동 구성

결과에 개인 티어·점수, 팀별 합계·평균·점수 차이를 표시합니다.

/내정보계정 상태 확인

등록된 Riot 계정, 상점 계정, 쿠키 상태, 기본 계정과 알림 설정을 한 번에 확인합니다.

/상점상점 조회 · 계정 관리

Riot 계정별 상점 연동과 조회, 기본 계정 설정을 관리합니다.

/상점연동 계정명:본계정 · 계정별 Riot Mobile QR 승인

/상점 계정명:본계정 · 선택 계정 상점 조회

/상점기본계정 계정명:본계정 · 계정명 없는 조회의 기본 계정 설정

/상점계정목록 · 연동 계정과 실제 Riot 닉네임 확인

/상점계정정리 · 쿠키가 만료된 세션만 정리

/상점계정이름변경 기존계정명:기본계정 새계정명:본계정 · 별칭 변경

/상점계정삭제 계정명:부계정 · 저장된 상점 세션 삭제

/상점알림 설정 시:9 분:0 · 매일 지정 시간에 상점 DM 알림

필요한 Discord 권한

채널 보기, 메시지 보내기, 메시지 기록 보기, 임베드 링크, 파일 첨부가 필요합니다. /팀짜기를 사용하려면 공개·비공개 스레드 만들기, 스레드 관리, 스레드 멤버 관리 권한도 추가하세요.

상점 이용 전 안내

상점 조회는 Riot Client QR 인증을 사용하는 비공식 기능입니다. 비밀번호를 봇에 입력하지 않지만, QR 승인으로 생성된 세션은 암호화되어 저장됩니다. 세션이 만료되면 /상점연동을 다시 실행해야 합니다.
