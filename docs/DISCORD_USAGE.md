# Discord 서버 적용 안내

## 1. 봇 초대 권한

봇 초대 시 OAuth2 Scopes는 다음을 선택합니다.

- `bot`
- `applications.commands`

봇 역할에는 최소한 다음 권한이 필요합니다.

| 권한 | 사용처 |
| --- | --- |
| 채널 보기 | 명령어와 스레드 확인 |
| 메시지 보내기 | 명령어 결과, 팀 모집 메시지 |
| 메시지 기록 보기 | 스레드와 이전 메시지 확인 |
| 임베드 링크 | 전적, 상점, 팀 결과 Embed |
| 파일 첨부 | Riot QR 이미지와 VP WebP 이미지 |
| 공개 스레드 만들기 | `/팀짜기 방식: 수동` |
| 비공개 스레드 만들기 | `/팀짜기 방식: 자동` |
| 스레드에서 메시지 보내기 | 팀 모집 진행 |
| 스레드 관리 | 자동 만료 및 취소 시 스레드 삭제 |
| 스레드 멤버 관리 | 자동 방식에서 주최자 추가 |
| 외부 이모티콘 사용 | 현재 필수 아님. VP는 프로젝트의 WebP 파일을 사용 |

권한은 서버 전체 관리자 권한 대신 봇이 사용할 채널에만 부여하는 것을 권장합니다.

## 2. Discord Developer Portal 설정

`GuildMessages` 인텐트를 사용합니다. 코드에서 이미 활성화되어 있으므로 봇을 재초대할 필요는 없습니다.

1. Developer Portal에서 애플리케이션 선택
2. `Bot` 메뉴 이동
3. `Privileged Gateway Intents`에서 일반 메시지 관련 설정을 확인
4. 저장

이 봇은 메시지 본문을 읽어 명령을 처리하지 않습니다. `/팀짜기` 모집 중 메시지 활동을 감지하기 위해 서버 메시지 이벤트를 사용합니다.

## 3. 명령어 등록

현재 배포 방식은 `DISCORD_GUILD_ID`에 지정한 한 서버에 즉시 등록합니다.

```powershell
npm run deploy
```

다른 서버에 적용하려면 `.env`의 서버 ID를 바꾼 뒤 다시 배포합니다. 같은 봇을 여러 서버에 동시에 적용하려면 전역 명령어 등록 방식으로 변경하거나 서버별 등록을 추가해야 합니다.

## 4. 명령어 사용법

### `/내정보`

등록된 Riot 계정과 상점 연동 상태를 한 번에 확인합니다.

- Riot ID와 지역
- 연동된 상점 계정과 기본 계정 여부
- 상점 쿠키 상태: `정상`, `재로그인 필요`, `조회 실패`
- 상점 알림 활성화 여부와 설정 시간

### `/상점알림`

계정별로 매일 지정한 한국 시간에 선택한 상점 계정의 오늘의 상점을 Discord DM으로 받습니다. 여러 계정에 각각 설정할 수 있습니다.

```text
/상점알림 설정 시:9 분:0 계정명:본계정
/상점알림 설정 시:21 분:30 계정명:부계정
/상점알림 목록
/상점알림 해제
/상점알림 해제 계정명:부계정
```

계정명을 생략하면 기본 상점 계정을 사용합니다. 해제할 때 계정명을 생략하면 모든 계정의 알림을 해제합니다. Riot 세션이 만료된 경우 상점 대신 `/상점연동` 재로그인 안내를 받습니다.

### `/소식알림` (관리자 전용)

한국 발로란트 공식 공지와 공식 게임 업데이트를 선택한 기존 텍스트 채널 또는 새 `발로란트-공식-소식` 전용 채널에 매일 전송합니다. 패치 노트, 신규 스킨, 요원·맵 및 국내 공지를 구분하며, 한국어판이 없는 공식 글로벌 업데이트도 포함합니다.

```text
/소식알림 설정 전송방식:선택한 기존 채널 사용 채널:#발로봇 시:9 분:0
/소식알림 설정 전송방식:새 전용 채널 생성 채널:#발로봇 시:9 분:0
/소식알림 상태
/소식알림 해제
```

명령어는 Discord 서버 관리자만 사용할 수 있습니다. 전용 채널 생성 방식을 선택하면 기준 채널과 같은 카테고리와 권한으로 채널을 만듭니다. 최근 2주 안에 게시된 미발송 기사만 하루 최대 5개 알리며 새 기사가 없으면 메시지를 보내지 않습니다.

### `/상점즐겨찾기`

관심 있는 스킨을 등록하면 연동된 계정의 오늘의 상점을 확인하고, 등장한 계정과 스킨을 DM으로 알려줍니다.

```text
/상점즐겨찾기 추가 스킨명:프라임 밴달
/상점즐겨찾기 일괄추가 스킨1:프라임 밴달 스킨2:오니 팬텀 스킨3:약탈자 카람빗
/상점즐겨찾기 목록
/상점즐겨찾기 삭제 스킨명:프라임 밴달
/상점즐겨찾기 전체삭제
```

`추가`, `삭제`, `일괄추가`의 스킨 옵션은 자동완성을 지원합니다. `일괄추가`는 `스킨1`부터 `스킨5`까지 최대 5개를 입력할 수 있습니다.

즐겨찾기를 추가하면 오늘의 상점을 즉시 확인합니다. 이미 등장 중이면 바로 DM을 한 번 보냅니다. 오늘 등장하지 않은 경우 다음과 같이 동작합니다.

- `/상점알림`이 설정된 계정: 설정한 시각의 상점 DM에 즐겨찾기 등장 여부를 함께 표시합니다.
- 상점 알림이 없는 사용자: 매일 한국 시간 오전 9시 상점 갱신 후 다시 확인하며, 등장한 경우에만 DM을 보냅니다.

알림에는 스킨이 등장한 연동 계정이 함께 표시됩니다.

```text
관심 스킨이 오늘 상점에 등장했습니다.

등장 계정: 본계정
관심 스킨: 프라임 밴달
```

여러 계정에서 즐겨찾기 스킨이 등장하면 계정별로 구분됩니다. 즐겨찾기는 Discord 사용자별로 관리되며, 등록과 삭제 결과는 본인에게만 표시됩니다. Riot 세션이 만료된 계정은 `/상점연동`으로 다시 로그인해야 합니다.

### `/계정등록`

본인의 Riot 계정을 등록합니다.

- `이름`: Riot ID의 `#` 앞부분
- `태그`: Riot ID의 `#` 뒷부분. `#`는 입력하지 않습니다.
- `지역`: `kr`, `na`, `eu`, `ap` 중 선택

예시:

```text
/계정등록 이름:GULING 태그:KR1 지역:한국/아시아 (kr)
```

등록된 계정은 `/전적`에서 기본 계정으로 사용됩니다.

### `/전적`

등록된 본인 계정의 전적을 조회합니다. 다른 사람의 계정을 조회하려면 명령어의 Riot 이름, 태그, 지역 옵션을 직접 입력합니다.

기본 조회 내용:

- 경쟁전과 일반게임만 포함한 최근 경기
- KDA, KD, 승률, ACS, ADR, 헤드샷 비율
- 캐릭터/총기/맵별 요약
- 현재 티어와 최고 티어
- 경기별 기록

`시즌`을 선택하면 선택한 시즌의 경쟁전·일반게임 기록을 별도 화면으로 확인할 수 있습니다. 시즌 화면에서는 최신순, ACS 높은 순, ACS 낮은 순 정렬과 페이지 이동을 사용할 수 있습니다.

### `/팀짜기`

- `방식: 수동`: 공개 스레드에서 참가자가 `참가` 버튼을 누릅니다.
- `방식: 자동`: 비공개 스레드에서 주최자가 Riot 이름, 태그, 서버를 입력합니다.
- `팀수`: 2팀 또는 3팀. 생략하면 2팀입니다.

최대 15명까지 등록할 수 있으며, 팀 나누기는 파워 스코어 합계가 가장 비슷한 조합을 계산합니다. 모집 중 메시지나 버튼 활동이 있으면 타임아웃이 연장됩니다.

팀 결과에는 플레이어별 현재 티어와 파워 스코어, 팀별 파워 스코어 합계와 평균, 팀 간 최고/최저 점수 차이가 표시됩니다.

### `/상점연동`

상점 조회 전 Riot Mobile QR 로그인을 한 번 수행합니다.

1. 먼저 `/계정등록`을 실행합니다.
2. `/상점연동`을 실행합니다.
3. Discord에 표시된 QR을 Riot Mobile 앱으로 스캔합니다.
4. Riot Mobile에서 로그인을 승인합니다.

QR은 5분 후 만료됩니다. Riot 아이디, 비밀번호, 이메일 인증 코드를 Discord에 입력하지 않습니다.

### `/상점`

QR 연동 후 본인 계정의 상점을 확인합니다. 버튼으로 다음 화면을 이동합니다.

- 오늘의 상점
- 장식 상점
- 번들
- 야시장: 판매 데이터가 있을 때만 활성화

상점 화면은 10분 후 만료됩니다. 세션이 만료되면 `/상점연동`을 다시 실행합니다.

### 상점 계정 관리

- `/상점계정목록`: 연동 계정, Riot 닉네임, 쿠키 상태를 확인합니다.
- `/상점계정정리`: 계정명을 생략하면 쿠키가 만료된 계정을 모두 삭제합니다. 계정명을 입력하면 해당 계정만 검사합니다.
- `/상점계정이름변경`: 계정 별칭을 변경합니다.
- `/상점계정삭제`: 선택한 상점 계정을 삭제합니다.

계정명 입력란은 자동완성을 지원하므로 직접 입력하지 않고 목록에서 선택할 수 있습니다.

## 5. 상점 기능 주의사항

상점 조회는 Riot 공식 공개 API가 아닌 Riot Client 인증 흐름을 사용하는 비공식 기능입니다. Riot 정책 변경이나 세션 만료로 동작하지 않을 수 있습니다. QR 세션 쿠키는 암호화되어 Supabase에 저장되므로 `.env`와 Supabase `service_role` 키를 공개 저장소에 올리면 안 됩니다.

상점 알림과 즐겨찾기를 사용하려면 `sql/schema.sql`의 `store_notifications`, `store_favorites` 테이블 생성 구문을 Supabase SQL Editor에서 실행해야 합니다. 기존에 단일 계정 알림 테이블을 만든 경우에는 `sql/multi_store_accounts.sql`의 알림 테이블 기본 키 변경 구문도 실행해야 합니다. 공식 소식 알림은 기존 프로젝트에서 `sql/valorant_news.sql`을 한 번 실행해야 합니다.

## 6. 봇 운영 명령어

PM2로 실행하는 경우:

```powershell
npx pm2 status
npx pm2 logs valorant-discord-bot --lines 30
npx pm2 restart valorant-discord-bot
npx pm2 save
```

코드나 `.env`를 변경한 뒤에는 봇을 재시작해야 합니다.
